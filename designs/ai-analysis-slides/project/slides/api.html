05 · API VÀ LỜI GỌI NỘI BỘ

Một API công khai, nhiều bước xử lý

Lời gọiDữ liệu và kết quả
POST /api/chatbot/askGửi message, history, image → reply và products (≤ 5).
LM Studio /chat/completionsQwen mô tả ảnh, phân tích yêu cầu, lọc ứng viên, soạn trả lời.
LM Studio /embeddingsBGE M3 tạo vector câu hỏi hoặc lô ragText.
MongoDB $vectorSearchindex, path, queryVector; 100 candidates → tối đa 20 kết quả.
SigLIP nội bộTạo vector ảnh chuẩn hóa trong tiến trình backend.

Mẫu phản hồi: {reply: "...", products: [{_id, name, price, image, similarity?}]}

LM_STUDIO_URL mặc định là http://localhost:1235/v1. API trả 400 nếu thiếu đầu vào hoặc ảnh sai định dạng; lỗi xử lý trả 500. similarity chỉ có khi kết quả đến từ truy vấn vector có điểm.
