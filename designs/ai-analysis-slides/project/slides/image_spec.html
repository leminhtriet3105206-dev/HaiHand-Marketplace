03 · ĐẶC TẢ CHỨC NĂNG

Tìm sản phẩm bằng hình ảnh

01 · Nhận ảnh

JPEG, PNG, WebP
Frontend ≤ 5 MiB
API nhận data URL

02 · Hiểu ảnh

Qwen mô tả nội dung và trích xuất ý định, bộ lọc.

03 · Truy xuất

SigLIP tạo vector; MongoDB tìm trên imageEmbedding.

04 · Trả lời

Qwen lọc kết quả và tạo reply cùng thẻ sản phẩm.

Dự phòng khi vector ảnh lỗi: dùng vector chữ từ mô tả ảnh, rồi tìm theo từ khóa.

Nguồn: báo cáo Word, mục 2.2 · 04

API kiểm tra chuỗi ảnh không quá 7 triệu ký tự. SigLIP là thư viện chạy trong backend, không phải API HTTP. Nếu không tạo được imageEmbedding khi người bán đăng bài, sản phẩm vẫn được lưu nhưng không có vector ảnh.
