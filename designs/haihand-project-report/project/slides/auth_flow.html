05 / LUỒNG XỬ LÝ

Tài khoản: API và dữ liệu

01

POST /api/users/register nhận name, email, password.

02

Backend kiểm tra dữ liệu, email trùng; tạo users với role Khách hàng.

03

POST /api/users/login kiểm tra email, password và trạng thái khóa.

04

Trả user đã lọc + JWT; lỗi đầu vào hoặc sai thông tin trả 4xx.

API · POST /api/users/register · POST /api/users/login

IN: name, email, password

OUT: user + token hoặc lỗi 4xx

DB: users
