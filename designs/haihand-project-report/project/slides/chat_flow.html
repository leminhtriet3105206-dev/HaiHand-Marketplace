Chat: API và dữ liệu

01

GET /api/messages/conversations/:userId và GET /api/messages/:user1/:user2 tải lịch sử.

02

POST /api/messages nhận senderId, receiverId, text, postId hoặc ảnh.

03

Backend lưu messages, tạo notification; Socket.io đẩy sự kiện cho người nhận.

04

PUT /api/messages/mark-read cập nhật tin và thông báo đã đọc.
