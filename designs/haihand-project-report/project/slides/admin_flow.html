Quản trị: API và dữ liệu

01

POST /api/admin/login xác thực admin; dashboard dùng quyền JWT hoặc session.

02

GET /api/admin/dashboard-stats tổng hợp users, posts, orders và doanh thu.

03

Admin duyệt seller, duyệt/ẩn posts, xử lý reports và settings.

04

Giải ngân hoặc hoàn tiền cập nhật orders, users và transactions.

API · POST /api/admin/login · GET /api/admin/dashboard-stats

IN: credentials; postId, sellerId, orderId

OUT: stats, trạng thái xét duyệt

DB: users, posts, orders, reports, settings
